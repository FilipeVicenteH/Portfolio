## ✨ Principais Recursos & Funcionalidades

- **Navegação Fluida & SPA**: Desenvolvido com React 19 e Vite para carregamento ultrarrápido e transições sem refresh.
- **Visualização Interativa de Projetos**: Modais detalhados para exibição de código, arquitetura de sistemas e demonstrações ao vivo.
- **Relatório de Suporte Técnico & Métricas**: Apresentação de habilidades operacionais em TI (N1/N2, SLAs, APIs, Webhooks).
- **Design Responsivo & Dark Theme**: Interface estilizada do zero com Tailwind CSS, typography otimizada e contraste refinado.
- **OpenGraph & SEO**: Meta tags configuradas para compartilhamento com preview de imagem no LinkedIn, WhatsApp e redes.

---

## 🛠️ Tech Stack & Arquitetura

- **Front-End**: React 19, JavaScript (ES6+), HTML5, CSS3, Tailwind CSS, Lucide Icons.
- **Build Tool**: Vite, ESBuild.
- **Hospedagem & Deploy**: Vercel (CI/CD automático via GitHub).

```
portfolio/
├── public/                 # Favicon, currículo PDF e imagens de preview OG
├── src/
│   ├── components/         # Componentes React reutilizáveis (Navbar, Hero, Projects, Skills, etc.)
│   ├── data/               # Informações estruturadas de projetos e habilidades
│   ├── App.jsx             # Componente raiz da aplicação
│   └── main.jsx            # Ponto de entrada
├── index.html              # Shell HTML com meta tags SEO/OpenGraph
└── vite.config.js          # Configurações do ambiente Vite
```

## ⚡ Rodando o Projeto Localmente

```bash
# 1. Clone o repositório
git clone https://github.com/FilipeVicenteH/Portfolio.git

# 2. Acesse a pasta do projeto
cd Portfolio

# 3. Instale as dependências
npm install

# 4. Inicie o servidor de desenvolvimento
npm run dev
```
